# 👜 Lumisac

Lumisac is a freelance e-commerce web application created to sell handmade girls' bags crafted at home with care and creativity.

This platform allows customers to explore different bag styles and place orders easily online.

---

## 🌟 About The Brand

Lumisac is a home-based handmade brand focused on stylish, practical, and unique bags for girls.  
Each product is carefully made with attention to detail and quality.

---

## 🚀 Features

- 🛍️ Browse bag collections
- 🌙 View different style variations (Morning / Night)
- 📦 Custom order form
- 📱 Fully responsive design
- ⚡ Modern and fast user interface

---

## 🛠️ Tech Stack

- **Next.js**
- **TypeScript**
- **Tailwind CSS**
- **PostCSS**

## ⚙️ Getting Started

Clone the repository:

```bash
git clone https://github.com/mohamed-mounib/lumisac.git
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open http://localhost:3000 in your browser.
